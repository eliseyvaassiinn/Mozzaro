# Mozzaro 🍕 

![.NET](https://img.shields.io/badge/.NET-8.0-purple?style=for-the-badge&logo=dotnet)
![Blazor](https://img.shields.io/badge/Blazor-WebAssembly-blue?style=for-the-badge&logo=blazor)
![Docker](https://img.shields.io/badge/Docker-Ready-2496ED?style=for-the-badge&logo=docker)

**Mozzaro** — это современное веб-приложение для заказа пиццы. Проект построен на платформе .NET с использованием многослойной архитектуры. Клиентская часть реализована на Blazor, а серверная — на ASP.NET Core Web API.

---

## 🛠 Технологический стек

В проекте используются современные технологии экосистемы Microsoft и инструменты контейнеризации:

| Компонент | Технологии / Фреймворки | Описание |
| :--- | :--- | :--- |
| **Backend** | ASP.NET Core Web API, C# | RESTful API для обработки запросов от клиента. |
| **Frontend** | Blazor WebAssembly, HTML, CSS | Интерактивный пользовательский интерфейс. |
| **Архитектура** | N-Tier (многослойная), Repository Pattern | Разделение бизнес-логики, доступа к данным и представления. |
| **Инфраструктура** | Docker, Docker Compose | Контейнеризация для быстрого развертывания. |

---

## 📁 Структура проекта

Проект разделен на несколько ключевых модулей для обеспечения масштабируемости и чистоты кода:

| Модуль (Проект) | Назначение | Ключевые компоненты |
| :--- | :--- | :--- |
| `Mozzaro.API` | **Точка входа бэкенда** | Контроллеры (`PizzaController`, `OrderController`, `UserController`), Swagger, настройки DI. |
| `Mozzaro.Application` | **Бизнес-логика** | Сервисы (`PizzaService`, `OrderService`), интерфейсы (`IUnitOfWork`, `IRepository`). |
| `Mozzaro.Client` | **Пользовательский интерфейс** | Страницы (`Menu.razor`, `Cart.razor`, `Checkout.razor`), стили, статические файлы (изображения). |

---

## ✨ Основной функционал

| Модуль | Возможности |
| :--- | :--- |
| 🍕 **Каталог** | Просмотр меню, фильтрация по категориям, просмотр детальной информации о пицце. |
| 🛒 **Корзина** | Добавление/удаление товаров, изменение количества, подсчет итоговой стоимости. |
| 💳 **Заказы** | Оформление заказа, указание адреса доставки, история заказов пользователя. |

## 🚀 Как запустить проект

### С использованием Docker (Рекомендуется)

1. Убедитесь, что у вас установлен [Docker Desktop](https://www.docker.com/products/docker-desktop/).
2. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/yourusername/Mozzaro.git
   cd Mozzaro
   ```
3. Запустите сборку и контейнеры:
   ```bash
   docker-compose up --build
   ```
4. Приложение будет доступно по следующим адресам (порты могут отличаться в зависимости от ваших настроек):
   * **Клиент (Blazor):** `http://localhost:5000`
   * **API Swagger:** `http://localhost:5001/swagger`

### Локальный запуск через Visual Studio / .NET CLI

1. Убедитесь, что установлен .NET SDK.
2. Восстановите зависимости и запустите API:
   ```bash
   cd Mozzaro.API
   dotnet run
   ```
3. В новом окне терминала запустите клиент:
   ```bash
   cd ../Mozzaro.Client
   dotnet run
   ```
