# Mozzaro Documentation

Welcome to the technical documentation of **Mozzaro**, an online pizzeria application.

## About the project

Mozzaro allows users to browse pizzas, manage their shopping cart, register, log in, and place orders.

## Architecture

The project follows Clean Architecture and contains six main projects:

- **Mozzaro.API** — REST API and HTTP endpoints.
- **Mozzaro.Application** — application services and business logic.
- **Mozzaro.Client** — Blazor user interface.
- **Mozzaro.Domain** — domain entities and core models.
- **Mozzaro.Infrastructure** — database access and repositories.
- **Mozzaro.Tests** — automated tests.

## Technologies

- C# and .NET 9
- ASP.NET Core Web API
- Blazor
- PostgreSQL
- Entity Framework Core
- Swagger / OpenAPI
- xUnit and Moq
